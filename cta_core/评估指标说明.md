# 评价指标设计

- 核心流程
  - 按配置周期与 bars 数量为每个日期与标的构建窗口（默认 next-day 从次日零点开始）
  - 计算基础量化与平滑组合，最后施加惩罚项得到评估指标
- 关键计算
  - ER = 净变动 / 路径长度；move_scale = 净变动 / ATR均值；er_amp = ER × move_scale
  - R² 为收盘价线性拟合决定系数
  - 平滑：er_smooth = 3x² − 2x³（x=clip(ER,0,1)）
  - 组合：eff_amp_logms_er_smooth = er_smooth × R² × (log(1+move_scale) + amp_beta × amp_comp)
    - amp_comp 为 max_amp_pct（pct 模式）或 max_amp_atr（atr 模式）
  - 惩罚：denom_pen = 1 + penalty_dd × adverse_atr + penalty_zz × zigzag_ratio
    - adverse_atr (代码中对应 drawdown_atr)：自适应反向回撤。若趋势向上则计算最大回撤(Drawdown)，若趋势向下则计算最大反向反弹(Drawup)。
  - 最终：eff_amp_logms_er_smooth_penal = eff_amp_logms_er_smooth / denom_pen


# eval_config 配置方法

- 主要字段
    - picks_csv：优先直接指定单个 CSV 文件路径
    - picks_path：目录或文件；为目录时搭配 picks_pattern 按模式选择
    - picks_pattern：fnmatch 模式；为空优先 final_select_results.csv，否则选最新 .csv
    - kline_period：支持 Xm/Xmin/Xh/Xd（如 1h、30m、1d）
    - bars：窗口内 K 线数量
    - out_dir：输出目录，默认脚本同目录 evl_output
    - kline_root：K 线数据根目录；支持 .parquet 和 .csv
    - segment_start_mode：next-day 或 same-day
    - amp_mode：pct 或 atr
    - amp_beta：振幅项权重
    - penalty_dd / penalty_zz：回撤与锯齿惩罚系数
    - do_visual：是否生成可视化（预留）
- 数据要求
    - 选币 CSV 至少包含 date 或 candle_begin_time，以及 symbol
    - K 线数据：时间列允许 datetime/candle_begin_time/timestamp/ts；价格列 open/high/low/close；成交量列 quote_volume 或 volume
